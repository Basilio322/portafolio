🔐 Control de Acceso RFID + ESP32
📅 2023–2025 · Prototipo IoT

Sistema de control de acceso físico basado en ESP32 y lector RFID MFRC522. Al acercar una tarjeta o llavero RFID, el dispositivo verifica el UID en una base de datos MySQL (nube o servidor local) y activa un relay para abrir la cerradura.

  • ESP32 como microcontrolador con Wi-Fi integrado.
  • Lector RFID MFRC522 para tarjetas y llaveros Mifare.
  • Servidor web empotrado en el ESP32 para configuración.
  • Base de datos MySQL en la nube (registro de accesos con timestamp).
  • Relay para control de cerradura eléctrica.

🏠 Domótica Educativa con ESP32
📅 2024–2026 · Proyecto educativo

Proyectos de robótica y domótica desarrollados con estudiantes del área técnica. Se integraron sensores de temperatura/humedad, ultrasonido para detección de distancia, y control de actuadores vía interfaz web alojada en el propio ESP32.

  • Sensor DHT11 para temperatura y humedad en tiempo real.
  • Sensor HC-SR04 para medición de distancia ultrasónica.

  • Panel web empotrado accesible desde cualquier dispositivo en la red.
